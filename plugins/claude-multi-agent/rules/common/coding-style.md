# コーディングスタイルルール

## 必須

- **ファイルサイズ**: 200-400行を標準、800行を上限とする（超過時は分割を検討）
- **イミュータビリティ**: オブジェクト・配列はコピーして新規作成、直接ミューテーション禁止
- **エラーハンドリング**: 例外は全レベルで捕捉し、意味のあるメッセージを付与する
- **ハードコード禁止**: マジックナンバー・固定文字列は定数または環境変数で管理する
- **入力バリデーション**: システム境界（ユーザー入力・外部API）ではスキーマベースのバリデーションを使用し、外部データを信頼しない

## 命名規則

- 変数・関数: `camelCase`
- 型・インターフェース・クラス: `PascalCase`
- 定数（再代入不可の値）: `UPPER_SNAKE_CASE`
- ファイル名: `kebab-case.ts`
