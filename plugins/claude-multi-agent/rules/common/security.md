# セキュリティチェックリスト

コミット前に以下の8項目を確認すること。

1. **シークレット管理**: APIキー・パスワード・トークンはコードに含めず、環境変数またはシークレットマネージャーで管理する
2. **入力バリデーション**: ユーザー入力・外部APIレスポンスはすべてバリデーションする
3. **SQLインジェクション対策**: クエリはパラメータバインディングを使用し、文字列結合禁止
4. **XSS対策**: テンプレートへの値埋め込みはエスケープ処理を施す
5. **CSRF対策**: 状態変更リクエストにはCSRFトークンを検証する
6. **認証・認可**: 各エンドポイントで認証済みか・権限があるかを確認する
7. **レートリミット**: 公開エンドポイントにはレートリミットを設ける
8. **エラーレスポンス**: スタックトレース・内部パスをレスポンスに含めず、ユーザー向けの汎用的なエラーメッセージを返す
